# Fonts

- **Special Elite Regular** (`SpecialElite-Regular.ttf`, weight 400): normal text. By Brian J. Bonislawsky / Astigmatic; [Google Fonts source](https://github.com/google/fonts/tree/main/apache/specialelite), [specimen](https://fonts.google.com/specimen/Special+Elite). Apache 2.0; retain `SpecialElite-LICENSE.txt` when copying the font.
- **Inter Black** (`Inter-Variable.ttf`, use weight 900 and optical size 32): emphasis letters. By Rasmus Andersson / The Inter Project Authors; [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/inter), [upstream](https://rsms.me/inter/). SIL Open Font License 1.1; retain `Inter-OFL.txt`. The file is the unmodified variable font, renamed locally; it supports weights 100–900. The cream paper scraps are drawn separately by the emphasis renderer.

Downloaded from the official Google Fonts repository on 2026-10-12. Both fonts are bundled for offline rendering. Inter Black is a close visual substitute for the supplied reference, not an identification of its original font.
